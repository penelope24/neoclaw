# YouTube 讲座笔记功能 — 实现计划

## 目标

将一个视频讲座的字幕，自动生成一份结构清晰的课堂笔记，包含三层内容：
1. **流畅文章**：还原讲座的完整叙述，去除口语停顿和重复
2. **结构化笔记**：提取核心概念、结论、要点，用表格/图标等呈现
3. **一句话总结**：100 字以内概括整个视频

---

## 整体流程

```
字幕原文（完整，无截断）
        │
        ▼
┌───────────────────┐
│  Step 1: 文章生成  │  可能多次 LLM 调用（长字幕分段生成后拼接）
└───────────────────┘
        │ 完整文章
        ▼
┌───────────────────┐
│  Step 2: 结构化笔记 │  1 次 LLM 调用
└───────────────────┘
        │ 笔记内容
        ▼
┌───────────────────┐
│  Step 3: 一句话总结 │  1 次 LLM 调用
└───────────────────┘
        │
        ▼
   拼接三层输出
        │
        ▼
  ToolResult → Agent → 用户
```

---

## 各步骤详解

### Step 1：文章生成

**目标**：把零散的字幕整理成连贯的叙述文，像一篇讲义。

**长度判断**：
- 字幕 ≤ 20,000 字符 → 一次调用生成完整文章
- 字幕 > 20,000 字符 → 切段，每段单独生成文章片段，最后拼接

**切段策略**：每段约 20,000 字符，在换行处切分，避免在句子中间截断。

**Prompt 原则**：
- 将口语转为书面语，补全停顿和碎句
- 保留所有实质内容，不遗漏，不添加字幕中没有的信息
- 保留重要的例子、数据、类比
- 输出按自然段落组织，不加标题

**每次调用 max_tokens**：4096（比默认 2048 更大，保证文章完整）

---

### Step 2：结构化笔记

**目标**：从文章中提取核心知识点，用最适合的格式呈现。

**输入**：Step 1 生成的完整文章

**Prompt 原则**：
- 让 LLM 根据内容性质自行判断格式：
  - 有对比关系 → Markdown 表格
  - 有步骤/流程 → 编号列表
  - 有核心术语 → 术语 + 定义
  - 有重要数据或例子 → 单独用 `>` 引用块标注
- 提取 4-8 个最重要的知识点或结论
- 不重复文章原文，只保留精华

**每次调用 max_tokens**：3000

---

### Step 3：一句话总结

**目标**：100 字以内，回答"这个视频讲了什么，看完能学到什么"。

**输入**：Step 1 的文章（前 3000 字符）+ Step 2 的笔记

**每次调用 max_tokens**：512

---

## 最终输出格式

```markdown
# 📖 [视频链接]

---

## 一、完整笔记

[Step 1 生成的文章]

---

## 二、核心知识点

[Step 2 生成的结构化笔记]

---

## 三、总结

[Step 3 生成的一句话总结]
```

## 代码改动

### `tools/youtube_summary.py`（主要改动）

`run()` 主流程改为：
```
fetch transcript
  → _generate_article()     # Step 1，内部处理分段
  → _generate_notes()       # Step 2
  → _generate_summary()     # Step 3
  → 拼接三层，返回 ToolResult
```

新增私有方法：
- `_generate_article(transcript, lang)` → `str`
- `_generate_notes(article, lang)` → `str`
- `_generate_summary(article, notes, lang)` → `str`

移除旧方法：
- `_map_reduce()`（被 `_generate_article()` 的分段逻辑取代）
- `_build_summary_prompt()`（被三个新方法取代）

### `llm/base.py`（小改动）

给 `simple_chat()` 加 `options` 参数，让调用方可以指定 `max_tokens`：

```python
def simple_chat(self, user_message, system_prompt=None, options=None) -> str:
```

## 预估调用次数与耗时

| 场景 | LLM 调用次数 | 预估耗时 |
|------|-------------|---------|
| 30 分钟视频（短字幕）| 3 次 | 1.5-3 分钟 |
| 60 分钟视频（中字幕）| 5-6 次 | 3-5 分钟 |
| 90 分钟视频（长字幕）| 7-9 次 | 5-8 分钟 |

等待时间较长，但每次调用结束后会自然衔接下一步，用户最终收到完整笔记。
